## v1.0.0 - 2026-10-07

First public research release.

### Included
- evidence-controlled advertising simulator and policy research modules
- causal, off-policy, delayed-conversion, calibration, and model-risk utilities
- executable Agent task and host-control framework
- CPU-compatible regression and unit tests
- curated v1 scientific and post-hoc result summaries
- GitHub Actions CI for tests, lint, and design validation

### v1 scientific disposition
- 192 Development observations completed.
- Supplemental held-out execution completed, while the original paired confirmation remains incomplete and underpowered.
- DPO selection was a predeclared tie-break, not evidence of higher executable task success.
- R3 neural superiority was not established.
- Final descriptive logloss: D1 0.251955, D2 0.252963, D4 0.254828.
- Post-hoc analysis identified calibration drift, concentrated error, challenger disagreement, material value concentration, and Agent operability/safety risks.

### Scope limits
No production deployment, live ad spend, commercial lift, or regulatory qualification is claimed. Raw/restricted datasets, model weights, and machine-specific execution evidence are not distributed in this release.
