# AURORA-Ads v1.0.0

AURORA-Ads v1.0.0 is the first public research release and closes the v1 scientific program plus its post-hoc model-risk appendix.

## Highlights

- 192 Development observations across prompt-only, SFT, DPO, and IPO.
- Supplemental held-out execution with 43 prompt-only and 44 DPO valid observations.
- Frozen R3 final comparison on 286,467 rows.
- D1 mature logistic achieved the lowest descriptive final logloss among the frozen comparators: 0.251955.
- D4 neural superiority was not established.
- Post-hoc diagnostics cover calibration, residual/error concentration, temporal and feature slicing, parameter stability, challenger disagreement, threshold/capacity curves, monitoring references, materiality, and Agent failure taxonomy.
- Formal model-risk findings are carried into the prospective v2 design.

## Important limitations

- Original paired Agent confirmation remains incomplete and underpowered.
- Agent executable-success remained zero in v1.
- No production, live-spend, commercial-lift, or regulatory claim is made.
- Raw/restricted datasets, model weights, and machine-local evidence are not included.

## Release contents

GitHub source archives contain the public source, tests, tools, and documentation. The attached evidence-summary ZIP contains the curated v1 result documentation and checksum manifest.
